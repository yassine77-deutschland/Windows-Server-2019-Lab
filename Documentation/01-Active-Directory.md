# Active Directory Domain Services (AD DS)

## Objective

Install and configure Active Directory Domain Services on Windows Server 2019.

## Environment

- Windows Server 2019
- Windows 10 Client
- VMware Workstation

## Steps

1. Configure Static IP
2. Install AD DS Role
3. Promote the Server to Domain Controller
4. Create Domain: ID.MA
5. Restart Server

## Result

The server became the Domain Controller of the domain ID.MA.
