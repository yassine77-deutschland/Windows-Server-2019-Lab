
# DHCP Configuration

## Objective

Configure DHCP on Windows Server 2019.

## Steps

1. Install the DHCP Server role.
2. Create a new DHCP Scope.
3. Configure the IP address range.
4. Configure the Default Gateway.
5. Configure the DNS Server.
6. Activate the DHCP Scope.

## Result

Clients automatically receive an IP address from the DHCP server.
