# Troubleshooting

## Issues Encountered

- Domain Join failed.
- DHCP client did not receive an IP address.
- Group Policy not applied.
- Domain users could not log in.
- DNS name resolution issues.

## Troubleshooting Steps

- Verify network connectivity.
- Check DNS configuration.
- Verify DHCP Scope.
- Check Active Directory.
- Run gpupdate /force.
- Review Event Viewer logs.

## Result

The issues were identified and resolved successfully.
